# Oxy One artwork

`floral.mp4` is the user-provided `floral_a.mp4`, converted from HEVC 2560×2560
into H.264/yuv420p at 720×720, without audio, with fast-start metadata. It retains
the six-second duration. `floral.jpg` is a still from the same video.

`OxyOneVideo` uses the still for reduced motion and while playback initializes.
Bloom owns the decorative placement and fade; the media never supplies UI colors.
