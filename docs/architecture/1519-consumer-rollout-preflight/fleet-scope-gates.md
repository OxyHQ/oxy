`workloadBindingScopes([], appScopes)` inherits only valid **non-privileged** application scopes. Allo, CrowdSource and Syra each have application `user:read`, an active workload binding with `scopes: []`, and no user grant in that inventory. This does not mean their service identity has zero effective scopes; it also does not grant `notifications:write` or `acting-as:offline`.
